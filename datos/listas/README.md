# Listas

Copia de las listas de seguimiento de Momento-A (`momento-a/`), Momento-B (`momento-b/`) y Scanner-pump
(`scanner-pump/`), un archivo por día (`AAAA-MM-DD.json`) tal como los guarda cada repositorio. La actualiza
cada día el workflow **Diario** con `python -m red_momentos.listas`; no hace falta editarla a mano. Si se
borra un día en el repositorio de origen, se borra también aquí.
